WHAT THE APP DOES — SUMMARY
============================

LTTStudio VideoBot is a Windows desktop tool that lets video content
creators bulk-publish pre-recorded videos to multiple Facebook Pages
they own, with optional scheduling, optional first-comment, and
engagement analytics — all driven by a Google Sheets row queue.


WHAT THE APP DOES NOT DO
========================

- Does NOT collect or transmit user PII beyond Page name and Page ID
- Does NOT share data with third parties
- Does NOT operate any LTTStudio backend server that stores FB data
- Does NOT post on behalf of users without explicit row-by-row sched
- Does NOT auto-generate content (creators supply ALL text/video)
- Does NOT support Instagram, Messenger, Ads, or Business management


DATA HANDLING
=============

  Page access_token:  encrypted at rest (AES-128 Fernet, bound to
                      Windows Machine GUID; cannot be moved between
                      machines)
  Sheet data:         read-only access; bot writes back only status
                      columns (status, uploaded_at, video_url,
                      video_id, error_message)
  Audit log:          local JSONL file (data/audit_log.jsonl);
                      records timestamp, event type, page_id,
                      video_id, error_code — no caption content,
                      no PII, no token values
  Video files:        downloaded to temp folder, deleted after each
                      upload (default behavior, can be disabled)
  Data deletion:      https://lttstudios.com/legal/data-deletion.html
                      User can self-service or email
                      akakenly.design@gmail.com — completed within
                      30 days
