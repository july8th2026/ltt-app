Data Deletion Instructions

LTTStudio VideoBot — Facebook App ID: 2021063792619148

What data we store

LTTStudio VideoBot is a desktop application. All user data is stored locally on the user's own machine — we do NOT operate any LTTStudio backend server that stores Facebook user data.

Data stored locally on the user's machine:

  • Facebook Page access tokens (AES-128 Fernet-encrypted, bound to Windows Machine GUID)
  • Page IDs and Page names of Pages the user connected to the app
  • Operation logs and audit trail (timestamps, post IDs — no caption content)
  • Temporary cached video files (auto-deleted after each upload by default)
  • Content history database (video hashes for duplicate detection, no video bytes stored)

How to delete your data

Option A — Self-service (instant)

  1. Close the LTTStudio VideoBot application
  2. Delete the folder containing the bot installation (this removes all local data)
  3. Revoke the app at Facebook Settings → Business Integrations — find "Lttstudio" and click Remove

This removes all access tokens, cached files, audit logs, and revokes Facebook access in a single workflow.

Option B — Email request

If you cannot perform Option A (e.g., you no longer have access to the machine), email akakenly.design@gmail.com with:

  • Subject line: Data Deletion Request
  • Your Facebook user ID OR the email address used during the OAuth connection
  • Confirmation that you want all data associated with your account deleted

Response time: We acknowledge within 5 business days and complete deletion within 30 days, as required by GDPR Article 17 and the Meta Platform Terms.

What you cannot delete from us

Because we do not run a backend server, there is nothing on LTTStudio infrastructure to delete. Content you have already published to your Facebook Pages remains on Facebook and is governed by Facebook's own data retention policies — to remove published posts, delete them directly from your Page using the Facebook UI or Meta Business Suite.

Dữ liệu chúng tôi lưu trữ

LTTStudio VideoBot là ứng dụng máy tính (desktop). Toàn bộ dữ liệu người dùng được lưu trên máy của chính người dùng — LTTStudio KHÔNG vận hành server lưu trữ dữ liệu Facebook của người dùng.

Dữ liệu lưu trên máy người dùng:

  • Token truy cập Facebook Page (mã hoá AES-128 Fernet, gắn với Machine GUID Windows)
  • ID và tên các Page bạn đã kết nối
  • Log thao tác và audit trail (timestamp, post ID — không lưu nội dung caption)
  • File video tạm trong cache (tự xoá sau mỗi lần upload)
  • DB lịch sử content (chỉ hash để chống trùng, không lưu byte video gốc)

Cách xoá dữ liệu của bạn

Cách A — Tự xoá (tức thời)

  1. Đóng ứng dụng LTTStudio VideoBot
  2. Xoá thư mục chứa bot (xoá toàn bộ dữ liệu local)
  3. Huỷ app tại Cài đặt Facebook → Công cụ kinh doanh — tìm "Lttstudio" và bấm Xoá

Cách B — Yêu cầu qua email

Nếu không thể làm Cách A (vd: không còn quyền truy cập máy), email akakenly.design@gmail.com kèm:
