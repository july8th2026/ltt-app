# 03 - Benchmark plan

Benchmark chưa được tuyên bố hoàn tất trong lượt lập plan. Mỗi app sẽ được đo
trên 5-7 sản phẩm bằng tài liệu chính thức và browser thật nếu có quyền truy cập.
Không chấm theo ảnh marketing.

| App/phạm vi | Tập benchmark đề xuất | Hành vi cần đo |
|---|---|---|
| Marketplace chung | Canva Apps, Adobe Creative Cloud, Freepik, Krea, Runway | discoverability, status, card click, filter, recent jobs |
| Upscale Video | Topaz Video AI, TensorPix, AVCLabs, HitPaw, CapCut | preset, queue, before/after, download, GPU expectation |
| Tạo Video Seedance | Kling, Runway, Luma, Pika, Veo surfaces | composer density, reference media, history, retry/remix |
| Prompt AI | LTX Studio, Katalist, Storyboarder class, Flora, PlenX | project IA, asset library, scene/storyboard/version/history |
| Auto Sub | CapCut, VEED, Descript, Submagic, Captions | upload/transcribe/style/timeline/render/recovery |
| Tạo ảnh hợp nhất | Midjourney, Firefly, Ideogram, Leonardo, Krea | create vs thumbnail mode, references, variants, history |
| Tạo Clip ngắn | OpusClip, Vizard, Munch, Captions, Klap | ingest, highlight, edit, batch, aspect, export |
| Chat AI | ChatGPT, Claude, Gemini, Perplexity | thread, attachment, streaming, retry, source/error states |
| Agent AI | Flora, PlenX, Make, n8n, ComfyUI | block grammar, run scope, history, recovery, non-dev UX |
| Social publishing | Buffer, Hootsuite, Metricool, Later, Sprout | chỉ audit maintenance/status; không mở feature mới |

Mỗi benchmark phải ghi: persona/JTBD tương đương, control registry, điểm tốt cần
học, điểm không phù hợp LTT, chi phí/phụ thuộc và bằng chứng E1-E4.
