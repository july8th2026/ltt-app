# Mẫu hồ sơ LTT-AQA

Đọc `docs/quy_tac_audit.md`, sau đó sao chép thư mục này thành
`docs/APP_AUDIT/<slug>/<YYYY-MM-DD>/`. Không sửa mẫu để ghi kết quả của một app.

Điền `UNKNOWN/CHƯA CHẠY` thay vì đoán. Evidence dùng ID ổn định như `EV-BR-001`,
`EV-TEST-001`; không lưu token, cookie, email thật hoặc dữ liệu production nhạy cảm.

Một hồ sơ chỉ được đóng khi 00–07 đồng bộ cùng app/version/snapshot date.
