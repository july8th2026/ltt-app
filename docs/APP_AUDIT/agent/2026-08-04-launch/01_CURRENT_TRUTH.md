# 01 — Current truth

## Bề mặt và năng lực thật

| Nhóm | Hiện trạng có bằng chứng |
|---|---|
| Shell | route toàn viewport, topbar 48 px, rail 48 px, drawer theo ngữ cảnh |
| Authoring | page/frame/note/comment, palette tìm kiếm, node visual-first, composer nhanh + Inspector nâng cao |
| Graph | typed DAG, cycle/type validation, drag edge và picker đích tương thích, hit-zone 44 px |
| Media | 11/11 nhóm capability H16; catalog/provider/model do server cấp |
| Execute | validate/quote, node/selection/frame/full, cache, approve, hold/settle, cancel/replay/artifact |
| Safety | ACL/ownership, optimistic revision, signed assistant apply, SSRF/upload limits, atomic credit |
| Recovery | autosave, snapshots, restore-as-new, rollout flag, release rollback |
| Responsive | desktop authoring; mobile inspect/approve/run, authoring bị khóa có chủ ý |

## Không được mô tả quá mức

- Assistant chưa phải VLM video-understanding độc lập.
- Collaboration không phải realtime cursor/multi-user editing.
- Chưa có kết quả usability study với người dùng ngoài đội; task-success 90% là
  target đo sau controlled launch, không phải bằng chứng hiện có.
- Authenticated production browser của bundle H17 phải được kiểm lại sau deploy;
  tab production hiện ở trang đăng nhập.
