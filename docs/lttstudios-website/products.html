LTTStudios VideoBot

A Windows desktop tool that lets video content creators bulk-publish pre-recorded videos to multiple Facebook Pages and TikTok accounts from a single Google Sheets queue.

At a glance

Feature breakdown

📤 Facebook Pages publishing (Graph API v21.0)

  • OAuth: POST oauth/access_token for long-lived token exchange + GET /me/accounts to list user's Pages
  • 3-phase resumable upload to POST /{page_id}/videos (feed format, up to 10GB, up to 4 hours)
  • 2-phase upload to POST /{page_id}/video_reels (Reels format, up to 90 seconds)
  • Scheduled publishing via scheduled_publish_time parameter — schedule weeks in advance
  • Thumbnail upload (optional, fails gracefully)
  • Video status polling until video_status=ready before considering the upload complete
  • Optional first-comment via POST /{video_id}/comments for affiliate links or context

🎵 TikTok account publishing (Content Posting API v2)

  • OAuth: POST /v2/oauth/token/ for access token + refresh token
  • Endpoints used: POST /v2/post/publish/inbox/video/init/ (draft), POST /v2/post/publish/video/init/ (direct), POST /v2/post/publish/status/fetch/ (polling), POST /v2/comment/create/ (comment)
  • 3 publishing modes: draft_upload (creator inbox), direct_private (SELF_ONLY), direct_public (requires app audit)
  • Privacy level enforcement per TikTok policy
  • Optional first-comment via POST /v2/comment/create/
  • Cross-machine OAuth via QR code (HMAC-signed relay)
  • ComplianceGuard pre-flight check for caption length, hashtag count, banned hashtags, AI-content disclosure flags

📊 Google Sheets queue

  • Read/write Google Sheets v4 — bot ticks every minute, picks rows whose schedule_time <= now
  • Multi-sheet, multi-tab, multi-worker (up to 20 concurrent)
  • Status writeback: status, uploaded_at, video_url, fb_video_id, upload_duration_s, error_message
  • Row color-coding: pending (yellow), running (yellow), done (green), error (red), skipped (gray)

📈 Engagement analytics (Monitor)

  • API: GET /{video_id}/video_insights?metric=post_impressions_unique,post_video_views,post_video_view_time for per-video stats
  • Background daemon refreshes insights every 30 minutes
  • Per-video stats: views, unique reach, reactions, comments count, shares, total minutes viewed
  • Insights fetched 24 hours after publish (Facebook needs time to populate) — configurable
  • Click-through to original post on Facebook

🛡 Anti-spam & safety features

  • SHA-256 content dedup — refuses to re-post the same video to the same Page within configurable window (default 30 days)
  • Perceptual hash dedup — catches re-encoded variants of the same video
  • Cross-target warning — alerts when the same video is posted to ≥3 different Pages in 7 days (page-farm pattern)
  • Caption rotator — optional, deterministic per-(target, video, day) caption variation
  • Video light variation — optional FFmpeg-based or metadata-only video file variation per target Page
  • Page warm-up cap — new Pages (< 30 days) get reduced daily publish caps automatically
  • Circuit breaker — pauses publishing to a Page after consecutive failures, with cooldown matching FB documented backoff values
  • Session lock — file-based cross-instance lock prevents two bot instances from publishing to the same account
  • Active hours — configurable daily window (default 7am-10pm) when publishing is allowed
  • Rate limiter — per-Page minimum interval (default 4 hours), per-account daily cap (default 12 posts), jitter to avoid bot signature

🔐 Authentication & tokens

  • OAuth 2.0 standard for Facebook (long-lived 60-day Page tokens) and TikTok (with refresh token support)
  • Tokens encrypted with AES-128 Fernet, key derived from Windows Machine GUID (cannot be moved between machines)
  • Background token refresher: auto-extends Facebook tokens 7 days before expiry, refreshes TikTok tokens before access_token expires
  • Multi-app pool for Facebook (rotate between multiple Meta apps for resilience)

📋 Audit & compliance

  • JSONL audit log with 10MB rotation, 5 backup files
  • Every publish, comment, upload, OAuth, and error logged with timestamp + event type + relevant IDs
  • No PII or caption content in audit log (coarse metadata only)
  • Audit log viewable in the Audit tab of the GUI
  • Designed to support Meta and TikTok review processes

Integrations

Required (you bring credentials):

  • Meta Developer App — your own app with pages_show_list, pages_manage_posts, pages_read_engagement, pages_manage_engagement
  • TikTok Developer App — your own client_key with user.info.basic, video.upload, video.publish (audit for direct public posting)
  • Google Cloud Project — OAuth 2.0 client OR service account with Sheets API + Drive API enabled

Optional:

  • Telegram bot — for failure notifications
  • FFmpeg — for video variation features (bot falls back to metadata-only variation if FFmpeg not available)

System requirements

  • OS: Windows 10 / 11 (64-bit)
  • Python: 3.10 or newer (bundled in Windows installer)
  • RAM: 2 GB minimum, 4 GB recommended for multi-worker mode
  • Disk: 500 MB for app + temporary video cache (configurable)
  • Network: Stable broadband; FB upload prefers ≥10 Mbps for large videos
  • Browser: Chrome / Edge / Cốc Cốc / Brave for OAuth flows
  • Optional: FFmpeg on PATH for full video variation

What it does NOT do

  • ❌ Does not generate content (text, captions, or videos via AI)
  • ❌ Does not scrape or download videos from other creators
  • ❌ Does not run on macOS or Linux (Windows-only currently)
  • ❌ Does not support Instagram cross-posting
  • ❌ Does not run as a SaaS — you install on your own machine
  • ❌ Does not have a mobile app
  • ❌ Does not integrate with paid analytics platforms
