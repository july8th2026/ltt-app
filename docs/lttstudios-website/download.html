What you get in the .zip

  • BOT_UP_FACEBOOK.exe — main application
  • run_gui.bat — launcher
  • setup_new_machine.bat — first-time setup script
  • requirements.txt — Python dependencies
  • data/config.json — default config (you customize via Settings tab)
  • secrets/ — empty folder for your credentials
  • LICENSE — license terms
  • README.md — quick start

Quick start (after extracting)

  1. Run setup_new_machine.bat — installs Python deps, validates config (~2 min)
  2. Run run_gui.bat — launches the GUI
  3. Go to Settings tab → fill in Meta App ID, TikTok Client Key, Google credentials path
  4. Go to FB Accounts tab → click Connect → OAuth via browser
  5. Go to Sheet FB tab → add a worker → click Start

System requirements

OSWindows 10 (1903+) or Windows 11, 64-bit
Python3.10 or newer (bundled in installer if missing)
RAM2 GB minimum, 4 GB recommended for 6+ workers
Disk500 MB for app, 5-10 GB free for video cache
NetworkStable broadband, ≥10 Mbps for large video uploads
BrowserChrome, Edge, Cốc Cốc, or Brave (for OAuth flows)
OptionalFFmpeg on PATH (for full video variation features)

Verify integrity

After downloading, verify the .zip with SHA-256 hash provided in the email. To verify on Windows:

certutil -hashfile lttstudios-videobot-v1.0.0.zip SHA256

Compare with the hash in the email. If they don't match, do not extract — email security@lttstudios.com immediately.

Antivirus & SmartScreen

First-run warning is normal

Because we're a small studio without code-signing certificates yet, Windows SmartScreen may show a warning on first run. Click More info → Run anyway.

If your antivirus quarantines the .exe, please email support@lttstudios.com with the AV vendor name — we'll submit the binary for false-positive review.
