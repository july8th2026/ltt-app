v1.0.0 — Tháng 6/2026 Hiện tại

Stable release đầu tiên. Build 2025-01.

Thêm

  • Migration domain sang lttstudios.com
  • Website public toàn diện (Privacy, Terms, Data Deletion, Cookies, DPA, Security, FAQ)
  • Sheet FB: schedule_time BẮT BUỘC
  • Sheet FB: tối đa worker 6 → 20

Đổi

  • Caption Rotator tắt mặc định
  • Perceptual hash threshold 8 → 2 — giảm false-positive 175× (từ ~70% xuống ~0.4%)
  • Reject degenerate hash values (all-zero 0000... và all-F ffff...) — tránh ghost-match
  • Sheet client: schedule_time giờ BẮT BUỘC — row trống bị skip
  • Bot version + build metadata được show trong footer mọi page web
  • Video status log dedupe + ẩn (0%) vô nghĩa

Sửa

  • False-positive perceptual hash
  • Stale .pyc cache sau migration
