Cam kết tuân thủ

Tuân thủ Platform Terms

Term: Dùng API chỉ cho mục đích cho phép

Bot chỉ gọi documented endpoint trong graph.facebook.com cho Page của user. Không scrape, không undocumented endpoint, không mobile API spoofing. Full endpoint list: Architecture page.

Term: Không enable spam, abuse, harassment

Multi-layer anti-spam tích hợp sẵn:

  • Hard rate limit: 4h giữa post cùng Page, 3 post/Page/ngày
  • SHA-256 + perceptual hash dedup (30 ngày)
  • Page warm-up cap cho Page mới <30 ngày
  • Circuit breaker theo FB error code 4, 17, 32, 368 (spam)
  • Caption Rotator OFF mặc định (không auto-CTA)
  • Active hours (default 7-22h) — không spam đêm khuya

Term: Respect rate limit

Bot honor FB rate limit với enforcement bảo thủ hơn limit thật của Meta. Backoff trên code=4, code=32, code=368.

Term: Dùng user data chỉ khi authorized

User authorize specific scope qua OAuth. Bot KHÔNG access:

  • Friend list (không request user_friends)
  • Private message (không read_mailbox)
  • Page user không admin
  • Data ngoài OAuth grant

Term: Privacy policy + data deletion

  • Privacy Policy: /vi/legal/privacy.html
  • Data Deletion: /vi/legal/data-deletion.html — 30 ngày completion theo GDPR Art. 17
  • DPA: /vi/legal/dpa.html

Term: Notify breach

Security policy cam kết 72-hour breach notification theo GDPR Article 33. Xem Security policy.
