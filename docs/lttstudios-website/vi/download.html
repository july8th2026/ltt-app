LTTStudios VideoBot cho Windows

Miễn phí cho creator cá nhân. Portable .zip không cần installer. Setup dưới 15 phút.

v1.0.0 · Stable

Bản mới nhất — Windows 10/11 (64-bit)

Build 2025-01 · Released tháng 6/2026 · ~50 MB

⬇ Yêu cầu link tải

Cấp link qua email để chống automated scraping. Nhận trong 1 business day.

Có gì trong .zip

  • BOT_UP_FACEBOOK.exe — ứng dụng chính
  • run_gui.bat — launcher
  • setup_new_machine.bat — setup script
  • requirements.txt
  • data/config.json
  • secrets/ — folder rỗng cho credentials
  • LICENSE + README.md

Quick start

  1. Chạy setup_new_machine.bat (~2 phút)
  2. Chạy run_gui.bat
  3. Settings tab → fill Meta App ID + TikTok Client + Google creds path
  4. FB Accounts tab → Connect → OAuth
  5. Sheet FB tab → add worker → Start
