Tính năng chi tiết

📤 Đăng Facebook Pages (Graph API v21.0)

  • OAuth: POST oauth/access_token exchange short-lived → long-lived token (60 ngày), GET /me/accounts liệt kê Page user admin
  • 3-phase resumable upload feed video (lên tới 10GB, 4 giờ)
  • 2-phase upload Reels (lên tới 90 giây)
  • Schedule publish trước hàng tuần
  • Upload thumbnail (optional)
  • Poll video status đến ready
  • Optional first-comment cho affiliate link/context

🎵 Đăng TikTok (Content Posting API v2)

  • OAuth: POST /v2/oauth/token/ cho access token + refresh token
  • Endpoints: POST /v2/post/publish/inbox/video/init/ (draft), POST /v2/post/publish/video/init/ (direct), POST /v2/post/publish/status/fetch/ (poll), POST /v2/comment/create/ (comment)
  • 3 mode: draft_upload, direct_private, direct_public
  • Privacy level enforcement theo policy TikTok
  • Optional first-comment
  • Cross-machine OAuth qua QR code (HMAC-signed)
  • ComplianceGuard pre-flight check

📊 Google Sheets queue

  • Multi-sheet, multi-tab, multi-worker (tới 20 song song)
  • Status writeback đầy đủ
  • Tô màu row theo trạng thái

📈 Engagement analytics

  • API: GET /{video_id}/video_insights?metric=post_impressions_unique,post_video_views,post_video_view_time cho per-video stats
  • Background daemon refresh insights 30 phút/lần
  • Per-video: views, reach, reactions, comments, shares, minutes viewed

🛡 Anti-spam & safety

  • SHA-256 dedup (mặc định 30 ngày)
  • Perceptual hash dedup catch re-encoded variant
  • Cross-target warning (page-farm pattern)
  • Caption rotator deterministic (optional)
  • Video light variation (FFmpeg hoặc metadata-only)
  • Page warm-up cap cho Page mới
  • Circuit breaker theo FB documented backoff
  • Session lock file-based cross-instance
  • Active hours (mặc định 7-22h)
  • Rate limiter min interval, daily cap, jitter

🔐 Authentication & tokens

  • OAuth 2.0 standard FB (long-lived 60 ngày) + TikTok (có refresh)
  • Token mã hoá AES-128 Fernet, key từ Machine GUID Windows
  • Background token refresher tự extend trước expiry
  • Multi-app pool cho Facebook

📋 Audit & compliance

  • JSONL audit log rotation 10MB, 5 backup
  • Mọi action đều log với timestamp + event + IDs
  • Không PII trong audit log
  • Designed support Meta + TikTok review

Integrations

Required (bạn cung cấp credentials):

  • Meta Developer App — app của bạn với scope pages_show_list, pages_manage_posts, pages_read_engagement, pages_manage_engagement
  • TikTok Developer App — client_key với scope user.info.basic, video.upload, video.publish (audit cho direct public)
  • Google Cloud Project — OAuth 2.0 client HOẶC service account với Sheets API v4 + Drive API v3 enabled

Open-source dependencies

Bot dùng tối thiểu third-party deps (xem requirements.txt):

  • customtkinter — GUI framework
  • Pillow — image processing
  • google-api-python-client, google-auth-oauthlib, google-auth — Google APIs
  • requests — HTTP client
  • cryptography — Fernet AES-128 encryption
  • qrcode[pil] — QR generation cho TikTok cross-machine OAuth
  • pytz, tzdata — timezone handling

KHONG analytics SDK, error reporting service, payment SDK. Mỗi dep review license + active maintenance.
