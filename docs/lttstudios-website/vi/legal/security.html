Bảo mật

Cách chúng tôi bảo vệ dữ liệu user, vulnerability disclosure policy, contact security team.

Hiệu lực: 02-06-2026 · Version 1.0

Kiến trúc: zero-backend by design

Property bảo mật quan trọng nhất của LTTStudios VideoBot: không có server LTTStudios nào lưu dữ liệu user. Không thể bị breach hàng loạt vì không có gì để breach. Token, sheet, log, video cache của từng user chỉ tồn tại trên máy Windows của họ.

Mã hoá at rest

Token

  • Thuật toán: AES-128-CBC + HMAC-SHA256 (Fernet spec)
  • Key derivation: SHA-256 hash of (Machine GUID + salt), salt riêng cho FB và TikTok
  • Key source: Windows Machine GUID (HKLM\Software\Microsoft\Cryptography → MachineGuid)
  • Hệ quả: token copy giữa máy không thể decrypt trên máy mới
  • File: data/tokens.enc (FB), data/tiktok_tokens.enc (TikTok)

OAuth state

CSRF state là 32-byte random (secrets.token_urlsafe(32)). Validate server-side trong callback.

TikTok OAuth relay (optional)

Cross-machine TikTok OAuth dùng HTTPS relay endpoint. Bot poll relay với HMAC-SHA256 signed request (timestamp 300s validity chống replay).

Transport security

  • Mọi API call dùng HTTPS với TLS 1.2+
  • Cert validation enforce (no verify=False)
  • OAuth callback serve qua HTTPS (Let's Encrypt cert)

Cái KHÔNG lưu

  • ❌ Password user (dùng OAuth — không thấy password FB/TikTok)
  • ❌ Caption content trong audit log (chỉ post ID và event type)
  • ❌ Video file content ngoài cache tạm khi upload
  • ❌ Email user message của bạn
  • ❌ Friend list hoặc contact graph
  • ❌ Analytics về bạn dùng bot thế nào

Audit log integrity

Audit log (data/audit_log.jsonl) là JSONL append-only với timestamp + event + minimal metadata. Rotation 10MB, 5 backup. Không tamper detection — security boundary là OS-level access control.

Dependency security

Chúng tôi minimize third-party deps. Current production (requirements.txt):

  • customtkinter — GUI framework
  • Pillow — image processing
  • google-api-python-client, google-auth-oauthlib, google-auth — Google APIs
  • requests — HTTP client
  • cryptography — Fernet
  • qrcode[pil] — QR cho TikTok OAuth
  • pytz, tzdata — timezone

Không analytics SDK, không error reporting, không payment SDK, không push notification SDK. Mỗi dep được review về license + active maintenance.

Vulnerability disclosure policy

Phạm vi

In scope:

  • Ứng dụng desktop LTTStudios VideoBot
  • OAuth callback flow (lttstudios.com/auth/*)
  • TikTok OAuth relay (lttstudios.com/api/oauth-relay/*)
  • Website marketing (lttstudios.com/*)

Out of scope:

  • Vulnerability trong third-party (Meta, TikTok, Google) — report cho vendor
  • Social engineering nhân viên LTTStudios
  • Physical attack hạ tầng LTTStudios (chúng tôi không có)
  • Vulnerability lý thuyết không có impact demonstrate

Quy trình report

  1. Email security@lttstudios.com với mô tả rõ, reproduction step, impact assessment
  2. Vuln nhạy cảm: request PGP key trong email đầu, chúng tôi sẽ provide
  3. Acknowledge trong 48h cho critical, 7 ngày cho lower severity
  4. Work toward fix + coordinate disclosure timing với bạn
  5. Public disclosure: credit researcher (với permission) trong changelog sau khi fix ship

Safe harbor

Nếu bạn good-faith comply policy này, chúng tôi sẽ:

  • Không pursue legal action
  • Không report law enforcement
  • Work với bạn để hiểu và resolve nhanh

Giới hạn đã biết / risk acknowledged

Machine GUID-based key derivation

Dùng Windows Machine GUID làm input PBKDF2 để mã hoá token. Attacker có admin access máy có thể đọc GUID từ registry và decrypt token. Đây là design — trust machine boundary, không phải user account boundary.

Chưa có code signing

.exe binary chưa sign Authenticode cert. User thấy SmartScreen warning lần đầu chạy. Plan add code signing 2026 H2 khi budget cho phép ($300+/năm cho EV cert).

Bot HTTPServer bind 127.0.0.1 only

OAuth callback receiver listen tại 127.0.0.1:8765 (FB) và 127.0.0.1:8766 (TikTok). Chỉ accept loopback, không LAN/WAN. Browser extension cùng máy có thể đọc OAuth code — same risk như mọi OAuth flow dùng localhost callback.

Lịch sử security advisory

Chưa có. Trang này sẽ document advisory tương lai với CVE number nếu có.
