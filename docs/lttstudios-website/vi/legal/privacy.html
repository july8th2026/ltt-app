1. Về chúng tôi

LTTStudios ("chúng tôi") là studio phần mềm độc lập tại Việt Nam, vận hành bởi LE THANH TRUNG. Chúng tôi phát triển công cụ tự động hoá desktop cho người làm nội dung video. Chính sách này giải thích cách sản phẩm LTTStudios VideoBot xử lý dữ liệu người dùng.

Liên hệ: akakenly.design@gmail.com · Mê Linh, Hà Nội, Việt Nam

2. Phạm vi áp dụng

Chính sách này áp dụng cho ứng dụng desktop LTTStudios VideoBot khi tương tác với Meta Graph API, TikTok Content Posting API, và Google APIs thay mặt người dùng chạy ứng dụng.

LTTStudios VideoBot là ứng dụng desktop. Chúng tôi KHÔNG vận hành server lưu trữ dữ liệu người dùng Facebook, TikTok, hay Google. Toàn bộ dữ liệu xử lý trên máy Windows của người dùng.

3. Dữ liệu chúng tôi truy cập và lưu

3.1 Từ Facebook (qua Meta Graph API)

Dữ liệuMục đíchLưu trữ
Facebook User ID + tên hiển thị Xác định account đang kết nối; hiển thị UI Local, mã hoá AES-128 Fernet
Page ID + tên Page Liệt kê Pages có thể publish (Page picker) Local, mã hoá
Page access token (long-lived) Cần để publish video và đọc insights Local, AES-128 Fernet, gắn Machine GUID Windows
Metadata video (post ID, URL) Ghi về Google Sheet để tracking Google Sheet của user (user kiểm soát)
Insights (views, reach, reactions, comments, shares) Hiển thị tab "Monitor" Cache local

3.2 Từ TikTok

Dữ liệuMục đíchLưu trữ
open_id, display_name, avatar_url Xác định account; hiển thị UI Local, mã hoá Fernet
Access + refresh token Publish video lên TikTok của user Local, mã hoá, gắn máy

3.3 Từ Google (Sheets & Drive)

Dữ liệuMục đíchLưu trữ
OAuth credentials (refresh token) Re-authenticate giữa các session Local, file token cạnh credentials
Row Sheet (video URL, title, description) Queue content bot xử lý Đọc trực tiếp; không lưu lâu dài
File video từ Drive link Tải về tạm, upload lên FB/TikTok, xoá Cache tạm, auto xoá sau publish

3.4 Dữ liệu chúng tôi KHÔNG thu thập

  • Không thu email, số điện thoại, tên thật, giấy tờ tuỳ thân vượt ngoài public profile Facebook/TikTok
  • Không truy cập friend list, tin nhắn riêng, hoặc data ngoài Pages user explicitly authorize
  • Không truy cập data TikTok ngoài account của user
  • Không thu telemetry hoặc analytics về hành vi user trong app

4. Cách sử dụng dữ liệu

  1. Xác thực user với Facebook, TikTok, Google.
  2. Publish video lên Pages/accounts user authorize.
  3. Hiển thị engagement analytics cho user.
  4. Maintain audit log để user xem lịch sử automation.

Chúng tôi không bao giờ sử dụng dữ liệu cho quảng cáo, training AI model, hoặc chia sẻ third party.

5. Chia sẻ dữ liệu

LTTStudios không chia sẻ dữ liệu user với bất kỳ third party nào. Service ngoài duy nhất bot liên hệ:

  • Meta Graph API (graph.facebook.com)
  • TikTok Content Posting API (open.tiktokapis.com)
  • Google APIs (googleapis.com)
  • Telegram API — chỉ khi user explicitly setup notification bot

6. Thời gian lưu trữ

  • Token: lưu đến khi user revoke hoặc xoá file. FB page token tự rotate ~60 ngày.
  • Audit log: local, rotation 10MB, max 5 backup.
  • Cache video: xoá sau mỗi upload (default; user có thể tắt).
  • Content history (SHA-256 hash): mặc định 90 ngày, configurable.

7. Xoá dữ liệu

User có thể xoá toàn bộ data bất kỳ lúc nào. Xem trang Xoá Dữ liệu.

8. Bảo mật

  • Mã hoá AES-128 Fernet với key từ Windows Machine GUID
  • Mọi API call dùng HTTPS / TLS 1.2+
  • Không backend → không thể bị breach hàng loạt
  • OAuth state validation chống CSRF
  • HMAC-signed TikTok OAuth relay

Chi tiết tại trang Bảo mật.
