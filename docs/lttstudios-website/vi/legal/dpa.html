DPA reference cho tổ chức subject GDPR dùng LTTStudios VideoBot.

Hiệu lực: 02-06-2026 · Version 1.0

Lưu ý quan trọng

LTTStudios VideoBot là ứng dụng desktop chạy hoàn toàn trên máy user. LTTStudios KHÔNG vận hành hạ tầng backend xử lý data thay mặt customer.

Với hầu hết user, điều này nghĩa là DPA riêng không cần thiết — bot xử lý data trên máy user, user vừa là controller vừa là processor. Trang này tồn tại cho user có team compliance yêu cầu DPA reference coi LTTStudios là software vendor.

1. Các bên

DPA này giữa:

  • Customer ("Data Controller"): cá nhân hoặc tổ chức dùng LTTStudios VideoBot
  • LTTStudios ("Software Provider"): studio độc lập vận hành bởi LE THANH TRUNG, Mê Linh, Hà Nội, Việt Nam

Lưu ý: vì LTTStudios không xử lý data user của Customer trên hạ tầng riêng, LTTStudios KHÔNG đóng vai trò "Data Processor" theo GDPR. LTTStudios là software vendor.

2. Phạm vi

DPA này áp dụng cho:

  • Ứng dụng desktop LTTStudios VideoBot
  • Website marketing tại lttstudios.com
  • OAuth callback handler + optional TikTok OAuth relay

3. Bản chất và mục đích xử lý

Bot xử lý các category data sau chỉ trên máy Customer:

  • Facebook Page access token + metadata (id, name)
  • TikTok account access token + basic profile
  • Google Sheets data qua OAuth credentials của Customer
  • File video tạm tải từ Drive của Customer
  • Engagement metrics cho post của Customer

5. Sub-processor

LTTStudios không có sub-processor cho data Customer vì data Customer không xử lý trên hạ tầng LTTStudios.

Cho website marketing LTTStudios, sub-processor:

  • Web hosting provider (serve static HTML/CSS) — xem trang liên hệ cho hosting partner hiện tại

6. Security measures

Cho LTTStudios VideoBot (software):

  • AES-128 Fernet mã hoá mọi token lưu trữ
  • Key từ Machine GUID Windows (token không di chuyển giữa máy)
  • TLS 1.2+ cho mọi API communication
  • OAuth 2.0 standard với CSRF state validation
  • HMAC-signed cross-machine OAuth relay
  • Audit log mọi operation nhạy cảm

Cho website LTTStudios:

  • HTTPS-only (Let's Encrypt hoặc tương đương)
  • HSTS khuyến nghị ở hosting layer
  • Không user account, không cookie

Xem đầy đủ Security policy.

7. Quyền data subject

Vì data Customer sống trên máy Customer, Customer chịu trách nhiệm honor data subject request (access, rectification, erasure, portability). LTTStudios cung cấp tool support:

  • Export audit log local (JSONL format)
  • Xoá token, log, cached data local — xem Data Deletion

8. Data transfer

Bot tạo outbound API call tới:

  • Meta (USA / Ireland)
  • TikTok (Singapore / Ireland tuỳ regional routing)
  • Google (USA / Ireland)

Đây là standard SaaS data transfer initiate bởi Customer dùng credentials của Customer. LTTStudios không kiểm soát third party đó lưu data Customer ở đâu — xem privacy policy + SCC riêng của họ.

9. Thông báo breach

Nếu LTTStudios phát hiện security incident ảnh hưởng software hoặc website có thể ảnh hưởng data Customer, sẽ thông báo Customer trong 72h qua email support, theo GDPR Điều 33.

10. Quyền audit

Cho compliance audit nội bộ của Customer:

  • Source code review có thể request qua licensing@lttstudios.com dưới NDA
  • Security questionnaire (SIG-Lite, VSA) complete best-effort

11. Term và termination

DPA này hiệu lực khi Customer cài đặt + sử dụng LTTStudios VideoBot và terminate khi Customer gỡ bot + revoke OAuth permission.

12. Luật áp dụng

DPA này tuân theo pháp luật Cộng hoà Xã hội Chủ nghĩa Việt Nam, nhất quán với Điều khoản Dịch vụ chính.

13. Liên hệ DPA

Email: licensing@lttstudios.com
Subject: DPA inquiry

Cho bản DPA PDF có ký phù hợp procurement workflow, email với tên công ty, chúng tôi gửi lại signed PDF trong 5 business days.
