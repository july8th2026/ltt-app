TikTok Developer Compliance

How we map every TikTok policy to specific bot behavior. Direct Post audit submitted 2026-05-22.

Our TikTok compliance commitment

LTTStudios VideoBot is built to comply with all TikTok Developer Terms of Service, Content Sharing Guidelines, and Community Guidelines. This page maps every TikTok policy area to specific bot behavior.

OAuth scopes & their use

ScopeWhat the bot doesWhere in code
user.info.basic Calls GET /v2/user/info/ after OAuth to display the connected account in the GUI (open_id, display_name, avatar_url). core/tiktok/auth_manager.py
video.upload Calls POST /v2/post/publish/inbox/video/init/ for draft uploads (creator manually reviews in TikTok app before publishing). core/tiktok/uploader_draft.py
video.publish Calls POST /v2/post/publish/video/init/ for direct posts. ONLY used after the TikTok app audit approves Direct Post. core/tiktok/uploader_direct.py

Content Sharing Guidelines compliance

Required: User consent for each post

Bot enforces user consent via the tiktok_confirmed_at sheet column. Each row must have a confirmation timestamp before the bot will publish — this satisfies TikTok's "Creator must take explicit action" requirement for Direct Post.

Implementation: core/tiktok/compliance_guard.py rejects any row missing tiktok_confirmed_at with error: ERR_NO_ACCOUNT or ERR_AUDIT_NOT_APPROVED depending on which compliance check fails first.

Required: Show TikTok branding on confirmation UI

The TikTok branding (logo + "TikTok" text) is displayed in the bot's confirmation dialog before publish. Source: gui/tiktok_oauth_disclosure.py.

Required: Privacy level enforcement

Until the TikTok app audit approves Direct Public Posting, the bot enforces privacy_level=SELF_ONLY automatically for all Direct Posts. This is enforced server-side in ComplianceGuard.enforce_sandbox_privacy() — user cannot override even via sheet column.

Required: Compliance disclosure URL

Per Content Sharing Guidelines, our Direct Post UI links to:

  • Privacy Policy: lttstudios.com/legal/privacy.html
  • Terms of Service: lttstudios.com/legal/terms.html

Audit log evidence

Every TikTok API call is logged in data/audit_log.jsonl with event types:

  • tiktok_video_uploaded — successful publish
  • tiktok_video_failed — failure with reason
  • tiktok_comment_posted — first comment
  • tiktok_validation_failed — rejected by ComplianceGuard
  • tiktok_token_refresh — refresh token rotation

What we DON'T do

  • ❌ Don't scrape TikTok videos or user data
  • ❌ Don't auto-generate content (creator supplies all videos)
  • ❌ Don't access friend lists or follower data beyond what OAuth grants
  • ❌ Don't bypass privacy_level restrictions
  • ❌ Don't bypass watermark requirements
  • ❌ Don't use undocumented mobile APIs
