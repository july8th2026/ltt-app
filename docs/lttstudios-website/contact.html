What to include in support emails

To help us help you faster, please include:

  • Bot version (visible in Settings tab → "Phiên bản")
  • Windows version (vd: Windows 11 Pro 23H2)
  • What you were doing when the issue happened
  • What you expected vs what actually happened
  • Last 50 lines of logs/app.log (or full log if small)
  • Screenshot of the GUI at the moment of the issue
  • Sheet headers if the issue involves Google Sheets

⚠ Please redact sensitive data

Before pasting logs or screenshots, please redact:

  • Access tokens (look for long alphanumeric strings)
  • Email addresses other than your own
  • Private Sheet IDs / Drive file IDs (replace last 10 chars with X)
