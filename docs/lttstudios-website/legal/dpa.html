Data Processing Agreement

Reference DPA for organizations subject to GDPR who use LTTStudios VideoBot.

Effective: 2026-06-02 · Version 1.0

Important context

LTTStudios VideoBot is a desktop application that runs entirely on the user's own machine. LTTStudios does NOT operate backend infrastructure that processes user data on behalf of customers.

For most users, this means a separate DPA is not required — the bot processes data on the user's own machine, with the user acting as both controller and processor. This page exists for users whose internal compliance teams require a written DPA reference for LTTStudios as a software vendor.

1. Parties

This Data Processing Agreement ("DPA") is between:

  • Customer ("Data Controller"): the natural or legal person using LTTStudios VideoBot
  • LTTStudios ("Software Provider"): independent studio operated by LE THANH TRUNG, Mê Linh, Hà Nội, Vietnam

Note: because LTTStudios does not process Customer's user data on its own infrastructure, LTTStudios does NOT act as a "Data Processor" in the GDPR sense for Customer's data. LTTStudios is a software vendor.

2. Scope

This DPA applies to:

  • The LTTStudios VideoBot desktop application
  • The associated marketing website at lttstudios.com
  • OAuth callback handlers and optional TikTok OAuth relay

3. Nature and purpose of processing

The bot processes the following categories of data on the Customer's machine only:

  • Facebook Page access tokens and Page metadata (id, name)
  • TikTok account access tokens and basic profile (open_id, display_name)
  • Google Sheets data accessed via the Customer's own OAuth credentials
  • Video files temporarily downloaded from the Customer's own Drive
  • Engagement metrics for posts published by the Customer

4. Controller / processor allocation

ActivityControllerProcessor
Storing tokens locally Customer None (self-hosted)
Calling Meta Graph API Customer Meta (per Meta's terms)
Calling TikTok API Customer TikTok (per TikTok's terms)
Calling Google Sheets/Drive API Customer Google (per Google's terms)
Marketing website visits (lttstudios.com) LTTStudios Hosting provider

5. Sub-processors

LTTStudios does not have sub-processors for Customer data because Customer data is not processed on LTTStudios infrastructure.

For LTTStudios' own marketing website, our sub-processors are:

  • Web hosting provider (for serving static HTML/CSS) — see contact page for current hosting partner

6. Security measures

For LTTStudios VideoBot (software):

  • AES-128 Fernet encryption of all stored tokens
  • Machine GUID-derived encryption keys (tokens cannot be moved between machines)
  • TLS 1.2+ for all API communication
  • OAuth 2.0 standard flows with CSRF state validation
  • HMAC-signed cross-machine OAuth relay
  • Audit logging of all sensitive operations

For LTTStudios website:

  • HTTPS-only (Let's Encrypt or equivalent)
  • HSTS recommended at hosting layer
  • No user accounts, no cookies (nothing to compromise)

See the full Security policy.

7. Data subject rights

Because Customer's data lives on Customer's own machine, Customer is responsible for honoring data subject requests (access, rectification, erasure, portability). LTTStudios provides tools to facilitate:

  • Local export of audit logs (JSONL format)
  • Local deletion of tokens, logs, and cached data — see Data Deletion

8. Data transfers

The bot makes outbound API calls to:

  • Meta (USA / Ireland)
  • TikTok (Singapore / Ireland depending on TikTok's regional routing)
  • Google (USA / Ireland)

These are standard SaaS data transfers initiated by Customer using Customer's own credentials. LTTStudios does not control where these third parties store Customer's data — see their respective privacy policies and standard contractual clauses (SCCs).

9. Breach notification

If LTTStudios discovers a security incident affecting our software or website that could affect Customer data, we will notify Customer within 72 hours via the email address used for support, in compliance with GDPR Article 33.

10. Audit rights

For Customer's internal compliance audit:

  • Source code review can be requested via licensing@lttstudios.com under NDA
  • Security questionnaires (standard ones like SIG-Lite, VSA) will be completed on a best-effort basis

11. Term and termination

This DPA is effective when Customer installs and uses LTTStudios VideoBot and terminates when Customer uninstalls the bot and revokes OAuth permissions.

12. Governing law

This DPA is governed by the laws of the Socialist Republic of Vietnam, consistent with the main Terms of Service.

13. Contact for DPA matters

Email: licensing@lttstudios.com
Subject line: DPA inquiry

For a signed PDF version of this DPA suitable for procurement workflows, email us with your company name and we'll send back a signed PDF within 5 business days.
