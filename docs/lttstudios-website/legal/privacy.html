1. Who we are

LTTStudios ("we", "us", "our") is a Vietnam-based independent software studio operated by LE THANH TRUNG. We develop desktop automation tools for video content creators. This Privacy Policy explains how our flagship product, LTTStudios VideoBot, handles user data.

Contact: akakenly.design@gmail.com · Mê Linh, Hà Nội, Vietnam

2. Scope

This policy applies to the LTTStudios VideoBot desktop application that interacts with the Meta Graph API (Facebook), TikTok Content Posting API, and Google APIs (Sheets and Drive) on behalf of the user who runs the application.

LTTStudios VideoBot is a desktop application. We do NOT operate any LTTStudios server that stores Facebook, TikTok, or Google user data. All data is processed locally on the user's own Windows machine.

3. Data we access and store

3.1 From Facebook (via Meta Graph API v21.0)

OAuth scopes requested: pages_show_list, pages_manage_posts, pages_read_engagement, pages_manage_engagement. These map directly to features described on our Products page.

DataPurposeStorage
Facebook User ID + display name Identify which Facebook account is connected; display in UI Local, AES-128 Fernet-encrypted
Page IDs and Page names List Pages the user can publish to (Page picker UI) Local, encrypted
Page access tokens (long-lived) Required to publish videos (scope: pages_manage_posts) and read insights (pages_read_engagement) on the user's Pages Local, AES-128 Fernet-encrypted, bound to Windows Machine GUID
Video metadata (post ID, video URL) Written back to user's Google Sheet for tracking User's Google Sheet (user controls)
Engagement metrics (views, reach, reactions, comments, shares) Displayed in the "Monitor" dashboard tab Local cache

3.2 From TikTok (via Content Posting API)

DataPurposeStorage
open_id, display_name, avatar_url Identify which TikTok account is connected; UI display Local, AES-128 Fernet-encrypted
Access token + refresh token Required to publish videos to user's TikTok account Local, encrypted, machine-bound
Video post IDs Written back to user's Google Sheet for tracking User's Google Sheet

3.3 From Google (Sheets & Drive)

DataPurposeStorage
OAuth credentials (refresh token) Re-authenticate to Sheets/Drive between sessions Local, in {credentials_path}.token.json
Sheet rows (video URLs, titles, descriptions, scheduling) The content queue the bot processes Read from user's own Google Sheet; not stored long-term
Video files from Drive shared links Downloaded to temp folder, uploaded to FB/TikTok, then deleted Temporary local cache, auto-deleted after each publish

3.4 Personal information we do NOT collect

  • We do not collect or transmit email addresses, phone numbers, real names, or government IDs beyond what is publicly available on the connected Facebook/TikTok profile.
  • We do not access Facebook friends lists, private messages, or any data outside the Pages the user has explicitly granted access to.
  • We do not access any TikTok data beyond the user's own account.
  • We do not collect analytics about user behavior in our application (no telemetry, no crash reporting service).

4. How we use the data

  1. Authenticate the user against Facebook, TikTok, and Google.
  2. Publish video content to Pages and accounts the user has authorized.
  3. Display engagement analytics to the user.
  4. Maintain an audit log so the user can review their own automation history.

We never use the data for advertising, training AI models, or sharing with third parties.

5. Data sharing

LTTStudios does not share user data with any third party. The only external services contacted by the bot are:

  • Meta Graph API (graph.facebook.com)
  • TikTok Content Posting API (open.tiktokapis.com)
  • Google APIs (googleapis.com)
  • Telegram API (api.telegram.org) — only if user explicitly configures notification bot

6. Data retention

  • Tokens: stored until the user revokes the app or deletes the local file. Facebook page tokens auto-rotate every ~60 days.
  • Audit log: kept locally with 10 MB rotation, max 5 backup files.
  • Cached videos: deleted after each upload (default behavior; user can disable in settings).
  • Content history database: SHA-256 hashes of published videos kept locally for deduplication, with configurable retention (default 90 days; anti_spam_retention_days).

7. Data deletion

Users can delete all data at any time. See our dedicated Data Deletion page for instructions.

8. Security

  • Encryption at rest: AES-128 Fernet (industry-standard) with a key derived from the Windows Machine GUID.
  • Transport: All API calls use HTTPS / TLS 1.2+.
  • No backend: We have no servers that could be breached to expose user data en masse.
  • OAuth state validation: CSRF protection on all OAuth flows.
  • HMAC-signed relay: optional TikTok OAuth relay uses HMAC-SHA256 signed payloads.

Full details on our Security page.

9. Compliance

  • Meta Platform Terms: We follow all Meta Platform Terms and Developer Policies.
  • TikTok Developer Terms: We comply with the TikTok Developer Terms of Service.
  • Google API Services User Data Policy: We comply with the Google API Services User Data Policy, including the Limited Use requirements.
  • GDPR (EU): Although our user base is primarily Vietnam, we honor GDPR rights for any user who requests them. See DPA page.

10. Children's privacy

LTTStudios VideoBot is not intended for use by children under 13. We do not knowingly collect data from anyone under 13.

11. Changes to this policy
