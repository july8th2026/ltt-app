Data Deletion Instructions

LTTStudios VideoBot · Facebook App ID 2021063792619148
Effective: 2026-06-02 · Version 2.0

What data we store

LTTStudios VideoBot is a desktop application. All user data is stored locally on the user's own machine — we do NOT operate any LTTStudios backend server that stores Facebook, TikTok, or Google user data.

Data stored locally on the user's machine:

  • Facebook Page access tokens (AES-128 Fernet-encrypted, bound to Windows Machine GUID)
  • TikTok account access tokens (same encryption)
  • Page IDs and Page names of accounts connected to the app
  • Operation logs and audit trail (timestamps, post IDs — no caption content)
  • Temporary cached video files (auto-deleted after each upload by default)
  • Content history database (video hashes for duplicate detection, no video bytes stored)

How to delete your data

Option A — Self-service (instant)

  1. Close the LTTStudios VideoBot application
  2. Delete the folder containing the bot installation (this removes all local data: tokens, logs, audit trail, content history database)
  3. Revoke the app at Facebook Settings → Business Integrations — find "Lttstudios" and click Remove
  4. For TikTok: open the TikTok app → Settings and privacy → Security and permissions → Manage app permissions → find LTTStudios → Remove

This removes all access tokens, cached files, audit logs, and revokes Facebook/TikTok access in a single workflow.

Option B — Email request

If you cannot perform Option A (e.g., you no longer have access to the machine), email akakenly.design@gmail.com with:

  • Subject line: Data Deletion Request
  • Your Facebook user ID OR the email address used during the OAuth connection
  • Confirmation that you want all data associated with your account deleted

Response time

We acknowledge within 5 business days and complete deletion within 30 days, as required by GDPR Article 17 and the Meta Platform Terms.

What you cannot delete from us

Because we do not run a backend server, there is nothing on LTTStudios infrastructure to delete. Content you have already published to your Facebook Pages or TikTok account remains on those platforms and is governed by their own data retention policies — to remove published posts, delete them directly from your Page using the Facebook/TikTok UI or Meta Business Suite.
