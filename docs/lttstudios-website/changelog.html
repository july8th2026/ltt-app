Changelog

Release history

What's new in each version. We follow SemVer — MAJOR.MINOR.PATCH.

v1.0.0 — June 2026 Current

First stable release.

Added

  • Domain migration to lttstudios.com (from lttstudio.top) — improves Meta App Review trust score
  • Comprehensive public website with Privacy Policy, Terms, Data Deletion, Cookie Policy, DPA, Security disclosure, FAQ, and product pages
  • Sheet FB: schedule_time now BẮT BUỘC — rows without schedule_time are skipped instead of running immediately (cleaner scheduling model)
  • Sheet FB: max workers raised from 6 to 20 (one per brand Page)

Changed

  • Caption Rotator disabled by default — no more auto-inserted CTAs or hashtags (was causing user confusion)
  • Perceptual hash dedup: tightened match threshold from 8 → 2 (eliminates ~70% of false-positive matches in old algorithm)
  • Perceptual hash: degenerate hash values (all-zero, all-F) now rejected at compute time and filtered from DB queries
  • Video status poll log: dedupe consecutive identical lines, hide meaningless (0%) when FB doesn't populate processing_progress

Fixed

  • False-positive perceptual hash matches that were rejecting legitimate uploads
  • Stale .pyc bytecode caches after domain migration

v0.9 — May 2026 Beta

Pre-release used for internal testing across 20+ brand Pages.

Added

  • Sprint A1: Caption Rotator with deterministic per-(target, video, day) variation
  • Sprint A2: Perceptual hash dedup (catches re-encoded variants)
  • Sprint A3: Cross-target duplicate warning (page-farm pattern detection)
  • Sprint A4: Video light variation (FFmpeg + metadata-only modes)
  • TikTok Direct Post audit submission flow (audit submitted 2026-05-22)
  • Session Lock — file-based cross-instance lock per account+platform
  • App Status monitor — periodic health check against Meta + TikTok
  • Multi-app pool for Facebook (rotate between multiple Meta apps)
  • Network Identity rotation (per-account UA + proxy when enabled)
  • Telegram notifier for token expiry, abuse signals, circuit-open events

Changed

  • Rate limiter rewrite — now coordinates across multi-worker mode
  • Token store: migration from JSON to AES-128 Fernet encrypted .enc files
  • Audit log: rotation 10MB, max 5 backups (was unbounded)

v0.5 — March 2026 Alpha

Added

  • TikTok integration: draft upload + direct private mode
  • Concurrent runner (up to 6 workers initially)
  • Insights fetcher (background daemon, 30-min poll)
  • Reels uploader (separate endpoint from feed videos)

v0.1 — January 2025 Initial

First internal build.

  • Single-worker Sheet → Drive → Facebook publish loop
  • Hardcoded rate limits (15-min between posts)
  • Console output only — no GUI
  • Plain JSON token store
