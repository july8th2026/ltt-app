# A2–A3 — Journey và control registry

| Bước | Outcome | Control/state bắt buộc |
|---|---|---|
| 1. Chọn nguồn | biết chính xác file/asset nào | upload, library, preview/summary, clear |
| 2. Chọn đầu ra | số clip + tỉ lệ | hai control chính, default an toàn |
| 3. Tuỳ chỉnh | chỉ mở khi cần | tier, brand, platform, genre, language, min/max |
| 4. Báo giá | hiểu credit trước submit | duration + output count + tier |
| 5. Tạo job | một lần nộp, có feedback | disabled/loading/error/credit/CSRF |
| 6. Theo dõi | thấy queued/running/done/error | progress + link nhật ký |
| 7. Khai thác | tải/so sánh/sửa package | owner-only, revision conflict, ZIP |

State test: empty, file/library selected, quote, validation, queued, done/error,
compare, save/stale revision, download, cross-tenant, desktop/mobile, i18n.
