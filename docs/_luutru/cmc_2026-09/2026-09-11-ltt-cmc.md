# LTT-CMC Master Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Consolidate LTTSTUDIOSAPP into one certified `main` history and one main worktree without losing valid Voice/LLM work or retaining competing archives.

**Architecture:** Four plans form a strict sequence. Phase 1 creates an immutable baseline without touching protected sessions; Voice and LLM independently reconcile to that exact SHA; final integration certifies the union and performs separately approved cleanup.

**Tech Stack:** Git, Python 3.13, pytest, Alembic, PowerShell, GitHub repository controls.

**Spec:** `docs/superpowers/specs/2026-09-11-ltt-cmc-design.md`

## Global Constraints

- Execute plans in the order below; do not overlap Git mutations across plans.
- Stop at `CMC_SYNC_BARRIER_READY` while Claude sessions are unavailable.
- Never touch a protected worktree from the Phase 1 executor.
- Never deploy production as part of LTT-CMC.
- Every heavy command requires both repository load/lock checks.
- Final deletion requires a fresh literal ledger and separate explicit approval.
