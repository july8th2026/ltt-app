## Quyết định transport (spec §13.1 nói SSE — 01b dùng polling, và đây là lý do)

| | SSE | Polling `GET /runs/{id}?sau=<seq>` |
|---|---|---|
| Mã máy chủ | vòng poll CSDL 1 s trong request, đóng sau 90 s, client nối lại | không có |
| Cloudflare | phải ở dưới trần 100 s — một hằng số phải nhớ | không chạm |
| Client | `EventSource`/reader + logic nối lại + gộp trạng thái | `setTimeout` — **CanvasShell đã có sẵn** (`CanvasShell.tsx:213-220`, nhịp 1200 ms) |
| Spec | §13.1 liệt kê; §19 xếp SSE vào **phase 13** (Quan sát) | §19 phase 1 chỉ đòi "Canvas lưu–chạy cùng một bản" |

⇒ 01b giữ đúng vòng `setTimeout` đang có, chỉ **đổi đích** từ `tickRun` (v2, client **lái** executor) sang `loadRunV3` (v3, client chỉ **đọc**). Khác biệt quan trọng không nằm ở SSE hay poll: nó nằm ở chỗ **client thôi lái động cơ**. Endpoint `?sau=<seq>` trả sự kiện tăng dần nên khi plan 13 thêm SSE, hợp đồng dữ liệu đã đúng hình — chỉ đổi vỏ.

```python
def _connect_args(url: str) -> dict:
    """Tham số riêng của driver. Chỉ PostgreSQL hiểu `connect_timeout`.

    ⭐ `options="-c timezone=UTC"` là tham số **libpq**: nó đặt `SET timezone`
       cho MỌI phiên ngay lúc bắt tay, trước câu lệnh đầu tiên. Không ghim thì
       `now()` trong SQL nói theo `timezone` của cluster — một giá trị nằm
       NGOÀI kho này — còn Python nói UTC (`_bay_gio()`), nên `due_at <= now()`
       của `danh_thuc`/`dong_co` lệch đúng bằng offset của máy chủ. Lệch đó
       không ném ngoại lệ: wakeup chỉ đơn giản không tới hạn.

    ⛔ `options` là của libpq, KHÔNG phải của `pysqlite` — nhánh SQLite phải
       giữ nguyên `{}`, nếu không `create_engine` ném `TypeError` cho cả kho.
    """
    if url.startswith(("postgresql", "postgres")):
        return {"connect_timeout": CONNECT_TIMEOUT_S,
                "options": "-c timezone=UTC"}
    return {}
```

```python
def _wf_cua_toi(db: Session, workflow_id: str, user_id: str) -> Workflow:

def _nodes_json(db: Session, run: WorkflowRun) -> list[dict]:
    """Trạng thái hiện tại của MỌI node trong đồ thị đã ghim.

    ⭐ Duyệt theo danh sách node của **version**, không theo các ảnh chụp đã

            "cost_credit": int(getattr(anh, "cost_credit", 0) or 0),
            "job_id": getattr(anh, "job_id", "") or "",

        "workflow_id": run.workflow_id,
        "version_id": run.version_id,
        "status": run.status,
        "credit_max": int(run.estimated_max or 0),

                     "du_lieu": dict(e.du_lieu or {}),
                     "created_at": _iso(e.created_at)} for e in su],

    }

    db.refresh(run)
```

```python
"""One-off §17.3 — đóng `AgentRun` chưa kết thúc, hoàn hold, trước khi drop bảng.

    python tools\\dong_agent_run_con_do.py          # chi DEM (mac dinh)

Chạy MỘT lần trên production, ngay trước migration drop `agent_runs`
(plan 01b Task 10). Số đếm ghi vào `docs/NHAT_KY.md`.
"""
from __future__ import annotations

import argparse

from platform_core.agent import budget
from platform_core.models import (AGENT_AWAITING_APPROVAL, AGENT_RUNNING,
                                  AgentRun)

#: Hai trạng thái CHƯA kết thúc. `planning` không giữ tài nguyên gì và không
#: có đường tự đi tiếp sau khi executor chết — để nguyên, nó sẽ đi cùng bảng.
DANG_DO = (AGENT_AWAITING_APPROVAL, AGENT_RUNNING)


def dong(db, *, that: bool = False) -> dict:
    rows = list(db.query(AgentRun).filter(AgentRun.status.in_(DANG_DO)).all())
    bao_cao = {"tim_thay": len(rows), "da_dong": 0, "hoan_credit": 0}
    if not that:
        return bao_cao
    for run in rows:
        # ⭐ `budget.cancel` tự phân hai nhánh: chưa duyệt ⇒ chuyển trạng thái
        #    KHÔNG chạm credit; đã duyệt ⇒ `settle(actual=0)` hoàn phần giữ.
        #    Gọi thẳng `credit.hoan` ở đây sẽ in tiền cho nhánh thứ nhất.
        truoc = int(run.estimated or 0) if run.status == AGENT_RUNNING else 0
        budget.cancel(db, run_id=run.id, user_id=run.user_id, actual=0)
        bao_cao["da_dong"] += 1
        bao_cao["hoan_credit"] += truoc
    db.flush()
    return bao_cao


def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--that", action="store_true", help="ghi that, khong chi dem")
    args = ap.parse_args()
    import platform_core.db as dbmod
    db = next(dbmod.get_session())
    try:
        bc = dong(db, that=args.that)
        if args.that:
            db.commit()
        print(f"tim_thay={bc['tim_thay']} da_dong={bc['da_dong']} "
              f"hoan_credit={bc['hoan_credit']} that={args.that}")
    finally:
        db.close()
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
