Cài đặt & an toàn

  1. Sau khi tải, đối chiếu SHA-256 (ghi ở mỗi nền tảng) với file bạn tải — khớp mới chạy.
  2. Windows có thể hiện cảnh báo SmartScreen (bản chưa ký): bấm More info → Run anyway, chỉ khi hash đúng.
  3. Mở app, đăng nhập tài khoản LTT. Máy sẽ gắn vào tài khoản của bạn.
  4. Muốn điều khiển máy khi vắng người: bấm Install trong app (nâng quyền một lần).
